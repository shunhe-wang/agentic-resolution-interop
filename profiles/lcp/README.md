# Experimental LCP resolver profile

This profile demonstrates how an LCP legal-context reference can identify exact terms and an experimental dispute-services catalog while resolution authority remains separately signed by both principals.

It is not an adopted LCP schema.

The verifier binds discovery, terms, clause, rules, catalog, provider, service, method, jurisdiction, and intake endpoint from caller-supplied exact bytes.

It performs no remote fetching.

The official Integra placement checks cover AP2, UCP, and x402.

The AP2 mandate is deliberately opaque because mandate verification remains an upstream precondition.
